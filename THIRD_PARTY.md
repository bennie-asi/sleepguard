# Third-party acknowledgements

Go dependencies and their exact versions are listed in `go.mod` and `go.sum`.
The project uses gopsutil, Cobra, go-toml, modernc SQLite, notify and its Telegram
integration. Their upstream licenses continue to apply.

The deterministic Finder layout writer in `scripts/dmg-layout.py` was written
for this project using the binary-format descriptions in
[ds_store](https://github.com/dmgbuild/ds_store) as a reference. No Python package
is installed or bundled. ds_store is distributed under the MIT license,
Copyright (c) Alastair Houghton and contributors.

The screen-lock symbol and runtime fallback were verified against Chromium's
[macOS login utility](https://chromium.googlesource.com/chromium/src/+/refs/heads/main/base/mac/login_util.cc).
No Chromium source code is included. The macOS `login.framework` API is private
and may change; SleepGuard reports failure instead of silently substituting a
screen saver or simulated keyboard input.

The app icon is original vector artwork generated by
`scripts/render-app-icon.swift`. Native interface symbols are Apple's SF Symbols.
