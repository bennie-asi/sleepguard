# SleepGuard 新功能原型

此目录保留已确认的 HTML 交互原型，作为原生界面的设计参考。SwiftUI 应用、Go 后台和 DMG 构建请查看项目根目录 README。原型不会修改用户规则、钥匙串或系统设置。

打开 `index.html`，或访问本机正在提供预览的 `http://127.0.0.1:8769/`。示例操作不读取凭据、不发送通知、不结束实际进程，也不真正黑屏或锁屏。

## 新增交互

- 设置页与菜单明确黑屏覆盖所有显示器。原型用内置屏幕与两个外接屏幕示意；任意按键或点击恢复全部屏幕。移除“黑屏期间保持 Mac 运行”的设置行，后台 AI 继续运行的行为保留。
- 增加黑屏、锁屏和打开 SleepGuard 的快捷键录入及清除入口，默认均未设置。录入常用系统组合或与其他功能重复时不保存；顶部示例状态还可查看其他应用占用时的反馈。原型只在页面内响应组合键，不注册全局快捷键。
- 添加规则默认展开应用搜索，尚未选中任何应用。搜索名称、Bundle ID 或路径，按全部、已启动、后台任务、未启动筛选。搜索框和分类固定在列表外，滚动长列表后无需返回顶部。手动填写为独立入口；编辑已有手动规则仍显示原标识。
- 通知页只保留系统通知开关、渠道配置与测试。长期授权使用 macOS 钥匙串原生的“始终允许”，不增加应用内授权面板、授权弹窗或授权状态场景。
- 异常应用在状态页和菜单中的应用操作区提供“结束应用”“强制结束”。两种操作分别确认，确认框显示应用标识和 PID。手动操作不依赖自动结束总开关，不修改规则。退出无响应时可再选择强制结束，不会自动升级操作。
- 系统进程、SleepGuard 自身、其他用户进程和无法可靠归属的请求不允许手动结束。真实实现会在执行前复核进程身份与最新请求；原型用“受保护进程”场景展示禁用状态。
- 菜单提供黑屏和锁屏两个快捷按钮，设置页也有入口。
- 黑屏采用所有显示器上的纯黑遮罩，保持 Mac 运行，不触发锁屏；任意按键或点击恢复。黑屏期间临时暂停休眠提醒和自动结束，返回后保留原有暂停状态、重新累计异常。屏幕本身不断电，也不修改系统锁屏设置。
- 锁屏立即锁定桌面，保留正在运行的应用，之后是否休眠遵循系统设置。原型以“模拟解锁”返回，不收集密码。
- 手动结束记录进入历史。刷新显示加载状态，菜单入口打开管理页后收起菜单。隐藏滚动条，保留页面滚动、悬停高亮和短动画，并遵循 Reduce Motion。

页面顶部可以切换快捷键与系统冲突、快捷键被其他应用占用、休眠异常、退出无响应、受保护进程、电报失败、正常监控、监控未运行等示例状态。

既有功能仍可演示：规则的通知／处理多选、多 Telegram 渠道独立配置、系统通知开关、预留渠道、暂停／恢复、保存与撤销。Token 输入值不持久化。

## 应用分发与安装

安装是最终发布包的必备流程，不属于应用界面或本原型。交付 DMG，窗口中提供 `SleepGuard.app` 与 `Applications` 文件夹快捷方式；用户拖入应用程序后，从应用程序或 Spotlight 打开。原型中不保留安装按钮、安装提示、安装设置或 Finder 模拟界面。原生发布包使用独立的 DMG 构建脚本，不在应用内添加安装页面。

原生应用直接启动 app bundle 内的 Go 监控子进程；“登录时自动启动”单独控制主应用登录项。原型中的监控状态不代表实际登录项状态，真实验收见 `../macos/VALIDATION.md`。

## 多屏与快捷键实现边界

原生黑屏应覆盖当前所有显示器，黑屏期间新增显示器也加入遮罩，拔掉屏幕后移除对应窗口。恢复时统一撤销遮罩及临时状态，不修改用户原有暂停设置。

常用系统快捷键、应用内重复组合与全局注册失败需分别处理。系统键位和第三方应用的占用会变化，不承诺枚举所有冲突；注册未成功时保留旧绑定并提示换组合。原型的“其他应用占用”是模拟状态。

## 凭据实现边界

长期读取权限由 macOS 钥匙串的“始终允许”维护，用户直接操作系统弹窗。应用内不再增加一层授权流程。说明见 Apple 的[允许应用访问钥匙串](https://support.apple.com/en-gb/guide/mac-help/kychn002/mac)。

原生实现的凭据访问与实际验证见 `../macos/VALIDATION.md`。原型本身无法验证钥匙串授权。

## 源文件与构建

`menu-bar.fragment.html` 为界面和交互源码，`icons.js` 为本地图标集。`index.html` 是可直接打开的独立产物，无外部脚本或网络依赖。

```sh
python3 prototypes/build.py
```

## 本轮验证

- JavaScript 语法与元素 ID 唯一性通过，确认生成页面不存在应用安装界面与被移除的设置行。
- 添加规则默认焦点在搜索框，手动字段隐藏；搜索 `com.microsoft` 返回 Visual Studio Code，选择后回填标识并能添加到规则草稿。
- 点击手动填写才展开名称、匹配方式与标识字段。
- 录入黑屏组合键后显示保存反馈；锁屏使用相同组合时被拦截，黑屏原绑定保留。系统冲突示例显示明确提示。
- 黑屏预览同时显示内置屏幕与两个外接屏幕；Escape 恢复后原有暂停 60 分钟状态保留。
- 浏览器没有控制台错误。菜单入口打开管理页后菜单收起。
- 已移除原型的自定义凭据授权区域、渠道授权按钮、授权弹窗及三个授权演示状态；电报配置和测试保留。

这些验证只涉及示例 UI。真实授权、真实信号发送、多显示器黑屏、全局快捷键、系统锁屏及后台 AI 持续运行，需在确认原型并实现后验证。

以 `index.html` 的交互页面为准。早期截图不随公开源码发布。
